# Integration notes

`midi_test.txt` holds the reports of real MIDI controllers (OPTIONS ▸ MIDI ▸ TEST ▸ COPY REPORT in any of the three apps): what each device sends, and the first messages. They are the source for the controller profiles in the apps (pad channel, first knob CC, number of keys).

The MPK mini Play mk3 has a second report at the end of the file (pads send a drum kit, the knobs have their own CCs).

Devices so far: Akai MPK mini Play mk3, Novation Launchkey, Synido Scale Pocket, Casio PX-S1100, Korg nanoPAD2, Korg nanoKEY2.
