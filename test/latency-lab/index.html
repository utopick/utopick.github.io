3 · Pedals

Choose Pedalboard as the processing path, start, put the headphones on and raise the monitor volume. Guitar in the instrument jack: pick its input channel (1 on a Scarlett Solo 4th Gen). Knobs work while playing.

DRIVE

DELAY

REVERB

Drive is a tanh clipper with a low-pass tone (oversampling is the only part that adds delay: measured above); the delay has feedback; the reverb is a generated noise tail in a ConvolverNode. Delay and reverb add their echoes after the dry sound, never delay it.

5 · Physical measurement

The real mic-to-headphone delay needs a reference sound and a two-channel recording (or an oscilloscope). Measure it outside, then attach it to a run here; it goes into the export.

The chirps are a test sound, not an automatic measurement. Start quiet. For a cable loopback, lower the level first; never connect a speaker amplifier output to an audio input.

How to compare

  1. Use HTTPS or localhost, allow the mic and pick the built-in microphone.
  2. Headphones on, monitor volume at zero unless you want to hear yourself.
  3. Record a run for Direct, Native, Worklet JS and Worklet WASM.
  4. Switch to the USB interface and repeat.
  5. Measure the round trip with a loopback (section 2) for each input and output.
  6. Export the JSON.

JS and WASM do the same gain, so they compare processing speed, not end-to-end delay. Runs only compare fairly with the same output route and capture settings.
